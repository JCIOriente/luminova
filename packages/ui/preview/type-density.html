Compact admin type scale

Five fixed-px steps for apps/backstage density, named by size (not role — one size carries many roles). Bundled line-heights are defaults an explicit leading-* overrides. Replaces 25 ad-hoc text-[Npx] values (incl. six half-pixel steps). Sizes ≥18px stay component-owned display numerals, outside this scale.
